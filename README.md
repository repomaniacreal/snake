# 🐍 Snake

The classic snake game as a single-file HTML5 game. Eat the food, grow longer, and don't crash into the walls or yourself!

## How to Play

- Steer the snake around the board to eat the red food pellets
- Each pellet scores **10 points** and makes the snake grow longer
- The snake speeds up a little with every meal, so stay sharp
- Game over when you hit a wall or bite your own tail

## Controls

| Input | Action |
|---|---|
| Arrow keys / WASD | Change direction |
| Swipe (touch) | Change direction |
| Play Again button | Restart after game over |

## Run It

Just open `index.html` in any modern browser — no build step, no dependencies, no server required. Works with keyboard on desktop and swipe on mobile.

## Tech

- Single HTML file, vanilla JavaScript + Canvas 2D
